# 天工仙阵 · 实际游戏接入

正式游戏名：**天工仙阵**。公开仓库仍叫 `lhl-go/Mindustry`；原项目来源为 Mindustry v160.7，作者及许可继续保留。

## 直接使用

下载 Release 中的 **Tiangong-Xianzhen-Art-v160.7.zip**。在桌面版 Mindustry v160.7 的“模组 → 导入模组”选择该 ZIP，启用后重启游戏。模块包含中文 Logo、窗口标题、地图、建筑、炮塔、单位、物品、特效和界面纹理，不需要手工拆图或重建 atlas。

这是基于原游戏的美术模块，不包含原游戏可执行文件。字体、技术遮罩、程序生成效果保留项和逐图来源见本仓库各清单；新增中文 Logo 见 [品牌文件](../../branding/tiangong-xianzhen/README.md)。模块没有新增玩法、服务器内容或全新 UI 逻辑。

## 打包处理

- 使用游戏支持的 `sprites-override` 与 FileTree 资源覆盖。
- 23 份自动拼接输入按该版本官方 `ImageTileGenerator` 的布局及坐标规则输出 1081 个图块。来源 SHA、目标及转换结果见 `mod-manifest.json`。
- 同时打入单位履带等运行时图层；原版自动生成的内容图标、轮廓与部件由初始化完成后的原版 `createIcons` 流程重建。正式内容的归属、属性和玩法规则保持原值。
- 高清 Logo 按适合主菜单的长宽比导出；源码覆盖版本仍保留原版 768×107 画布合同。
- 构建命令：`python full-game/integration/build_mod.py`。需要 JDK 17 或更高版本，以及 `.work/runtime-acceptance/Mindustry.jar` 的官方 v160.7 客户端。该 JAR 不纳入美术仓库。

## 验收范围

桌面客户端实际加载与渲染结果见 `qa/runtime-acceptance.json`，截图、运行时计数及测试源码一并提供。检查全量地形/建筑与独立单位类型、菜单 Logo、设置界面，并检查运输、液体、门、炮塔方向和部分程序特效的动态显示。离线界面设计的 616 个桌面/移动状态另经 Chromium 导出检查；这些设计预览不等同于已重写原游戏所有窗口布局。

本次运行验收针对 Windows 桌面 OpenGL 客户端。移动设备、联机压力与所有战役流程不在这份美术验收的测试范围。

模块内同时附带对应接入源码、官方自动拼接源码和 Mindustry GPL 许可证全文，便于独立核对与重建。完整制作材料及逐图证据保存在仓库，而非只保留可执行模块。
