# 建筑与运行层素材

本目录覆盖固定 Mindustry v160.7 的 759 个建筑源路径，另 145 个炮塔路径在 `../root-turrets`。301 张原生建筑、连接形状及独立部件保留实际尺寸；兼容输出保持原版画布、锚点、连接几何及运行时图层语义。

`manifest.json` 逐项记录新图派生、原版几何与技术复用，`batches` 及 `qa` 保存实际视检、分层、方向、相位和哈希证据。`integrationGeometryInputs` 是重建技术派生必需的原版几何输入，不能按已消费参考图清除。兼容小图的缩放、着色、清理和组合不算新模型生成或新原生细节。

传送带、推进器、旋转头与旋转指示层分别按源码方向处理；液体窗口、连接与状态及门洞使用已核验的原版透明几何。大型核心推进器原生顶端装饰有 3 个像素触及源板边界，喷嘴完整，未重绘缺失细节。已完成静态素材核验，未声称启动并验收实际游戏客户端。
