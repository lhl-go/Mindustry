本次范围是 Mindustry v160.7（`17012d61d9e4c3cbd9820d87e81c24495486ac53`）的 UI 与角色／单位美术。包含 28 类主要界面、16 类复用弹窗、20 类共用组件；原清单 281 类状态外，补入 21 类建筑配置和 6 类地图资源，共 308 类状态。单位清单共 69 个 ID，其中 `block` 是内部建筑代理，无独立图；其余 68 项已交付独立美术及必要分层。308 类状态已导出桌面和移动横屏两套，共 616 张 PNG。运行时接入与动态动画不在已验收范围。

保持整个 `mindustry-image` 文件夹结构。`exports` 是交付入口和索引，PNG 本体保存在上表目录，避免复制两套正式素材。AI 生成图与派生资源的 `.generation.json` 或 `.derived.json` 跟随图片保存；浏览器状态 PNG 逐文件记录在 `../records/ui-render-*.json`，包含尺寸、SHA256、状态、视口和页面输入哈希。历史源图已按保留规则删除的，文字记录仍保留原生尺寸、哈希、裁切坐标及调用证据。

## UI 规格

桌面布局基准为 1366×768，移动横屏为 844×390。文字使用客户端原生文字，不从整屏 PNG 裁取。预览采用 Microsoft YaHei／Noto Sans CJK SC 字体回退；标题采用 KaiTi 回退。未随包复制系统字体。常规正文 15–18 px、说明 12–14 px；移动参考 11–13 px，实际设备须按 DPI 和可触达区域复核。

九宫格数值依次为 **左、下、右、上**，单位为源 PNG 像素。整体标题牌、圆形图标按比例缩放；可伸缩框板只拉伸中心和对应边，不拉伸四角。控件层级为玉绿主按钮／选中态、米白正文／次要按钮、暖金边线；错误与危险状态使用朱砂提示。

`preview.js` 定义基本页面，`screen-variants.js` 定义页面与专用建筑状态，`dialog-component-variants.js` 定义弹窗和控件状态，`screen-audit-fixes.js` 补齐逐状态内容。客户端可以按 `manifest.json` 中的官方功能来源与 ID 逐项接入。PNG 整屏尺寸是浏览器渲染尺寸，不是图像模型原生分辨率。

## 单位规格

单位朝向以图像上方为前方，透明边距和原生主体大小见各 worker 清单。独立炮塔、机体、腿、翅片及多段生物按分层记录组合。完整单位图可能是分层的静态合成预览；需要旋转或运动的单位应使用独立部件，不能把合成图当作所有运行层。

世界尺寸、region 名、缩放倍率、队伍着色、旋转中心及动画幅度由客户端按官方单位定义设置。清单里的 `estimated_art_alignment` 是美术对齐估计，尚不是经过游戏运行验证的枢轴。引擎光、尾迹、爆炸等按清单复用官方程序效果，没有烘焙为静态火焰。分段单位的动态接缝仍需客户端验证。

## 图像与验证证据

生成目标沿用 `gpt-image-2.5-sunburst / max`，通过宿主内置 `image_gen` 生成。该入口未提供型号、画质或尺寸选择参数，返回值也未披露精确版本与质量，因此实际型号／质量记为未确认。提示词与配置目标不作为锁定型号的证明。

原生返回尺寸逐图记录；没有放大冒称新细节。本地清理和切片已经用户明确授权，只处理透明边缘、裁切、留白、必要的部件组合和控件状态派生。原始生成源板可低于请求目标；更大的透明画布或浏览器输出不代表更高原生细节。

`records/ui-render-*.json` 记录浏览器逐状态检查，`records/workers/*/verification.json` 等记录单位检查，`records/first-batch-resolution.json` 记录首批问题的最终处理。网页中的存档、服务器和模组均是演示数据；按钮不会实际读写存档、联网加入游戏或下载模组。

本包没有修改 Mindustry 客户端、服务端或共享 Git 状态。浏览器布局、透明 PNG 和来源检查通过后仍须在目标游戏中验证 atlas 装载、单位旋转、分层动画、触控尺寸和真实文本长度。

最终验收见 [验收汇总](../records/acceptance-summary.json) 与 [全文件验证](../records/final-delivery-verification.json)。旧检查图片已被最终导出取代，历史文字记录保留；清理对应关系见 [清理记录](../records/superseded-ui-image-cleanup.json)。

自动审批拦截了 32 张中间图的批量删除，未给出具体原因；没有绕过或重试该删除。本地保留这些文件，正式 ZIP 排除清单中的中间图，全部正式素材与来源文字保留。参见 [打包排除清单](../records/package-exclusions.json)。
